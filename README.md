# АвтоЖурнал — приложение для Android

Журнал автомобиля: заправки и реальный расход, замены масла и расходников с уведомлениями, цены работ и запчастей, где и кто делал, контакты мастеров, фото, несколько машин.

Kotlin + Jetpack Compose (Material 3), база Room, фоновые уведомления WorkManager. Android 8.0 и новее. Все данные хранятся только на телефоне.

## Что умеет

**Гараж и смена авто**
- Несколько автомобилей, переключение в одно касание (аватар машины в шапке → список).
- Фото авто с камеры или из галереи, марка/модель/год/госномер/VIN/топливо/бак.
- Иконка приложения — автомобиль (адаптивная, поддерживает тематические иконки Android 13+).

**Заправки**
- Дата, пробег, топливо, литры, цена, сумма — любые два поля, третье считается само.
- Расход л/100 км методом «полный бак → полный бак» (как в Fuelio), отметка «пропустил заправку».
- Подсказки АЗС из прошлых заправок и контактов, подстановка прошлой цены и марки топлива.
- График расхода, средняя цена литра, всего залито и потрачено.

**Сервис и расходы**
- 28 категорий: масло, фильтры, свечи, тормоза, ГРМ, шины, ремонт, мойка, страховка, налог, штрафы…
- Стоимость работ отдельно, запчасти списком: название, артикул/бренд, цена, количество. Итог считается сам.
- «Где делали»: выбор из контактов или новое место — сразу сохраняется в контакты с телефоном.
- Фото чека / заказ-наряда, поиск по работам, запчастям и артикулам, фильтр по категориям.

**Напоминания о замене (с уведомлениями)**
- Интервал по пробегу и/или по времени — что наступит раньше (как в Drivvo).
- Типовой регламент одной кнопкой: масло 10 000 км/год, фильтры, свечи, тормозная жидкость, антифриз, КПП, ГРМ, сезонная смена шин, ОСАГО.
- Прогресс-бар и цвет статуса (норма / скоро / просрочено), прогноз даты по среднему пробегу в день.
- Запись в «Сервисе» той же категории автоматически сбрасывает счётчик.
- Уведомления: проверка дважды в сутки; «скоро» — один раз, «просрочено» — раз в 3 дня; напоминание обновить пробег, если он не вводился 2 недели.

**Контакты**
- СТО, мастера, магазины запчастей, эвакуатор, страховая и т.д.
- Звонок и открытие адреса на карте в одно касание.
- В карточке контакта — история: что там делали и сколько всего потрачено.

**Статистика и данные**
- Расходы за 30 дней / год / всё время, стоимость 1 км, разбивка по категориям, столбцы по месяцам.
- Отчёт «Поделиться» текстом (мессенджер, почта).
- Резервная копия в JSON и восстановление; экспорт в CSV для Excel.
- Светлая и тёмная тема.

## Что взято у похожих приложений

| Приложение | Что позаимствовано |
|---|---|
| Fuelio | Расход «от полного до полного», отметка пропущенной заправки, график расхода |
| Drivvo | Напоминания «по км или по дате — что раньше», несколько авто, напоминание обновить пробег |
| Simply Auto / aCar | Стоимость 1 км, отчёты по категориям, справочник мастерских, экспорт в CSV |
| Дневники ТО (Бортжурнал и т.п.) | Запчасти с артикулами, фото чеков, типовой регламент ТО |

## Как получить APK

Собрать APK в этой среде нельзя (нет доступа к репозиториям Google), поэтому есть два простых пути.

### Вариант 1 — без установки программ (GitHub)
1. Зарегистрируйтесь на github.com, нажмите **New repository**, назовите `AutoJournal`.
2. **Add file → Upload files** — перетащите *содержимое* папки проекта (включая скрытую папку `.github`; если браузер её не берёт — создайте файл `.github/workflows/build.yml` вручную через **Add file → Create new file** и вставьте его текст).
3. Откройте вкладку **Actions** — сборка запустится сама (≈5–8 минут).
4. Откройте завершённый запуск → внизу **Artifacts → AutoJournal-apk** → скачайте zip, внутри `app-release.apk`.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

### Вариант 2 — Android Studio
1. Установите Android Studio (бесплатно), **File → Open** → папка `AutoJournal`.
2. Дождитесь синхронизации Gradle, подключите телефон по USB (режим разработчика → отладка по USB) и нажмите ▶ **Run**.
3. Или **Build → Build APK(s)** — файл появится в `app/build/outputs/apk/`.

Если при сборке появится ошибка — пришлите её текст, поправлю.

### Обновления
Проект подписывается постоянным ключом `app/autojournal.jks`, поэтому новые версии ставятся поверх старых без потери данных. Не удаляйте этот файл. Перед переустановкой на другой телефон сделайте резервную копию (Настройки → Сохранить копию).

## Структура

```
app/src/main/java/com/autojournal/app/
  App.kt, MainActivity.kt
  data/      Entities (Room), Dao, AppDatabase, Repository, Backup (JSON/CSV)
  domain/    Calc (расход, сроки, прогноз), Categories (категории, типовой регламент)
  notify/    Notifications, ReminderWorker (фоновые проверки)
  ui/        AppRoot (навигация, смена авто), MainViewModel, theme, components, screens
  util/      форматирование дат/денег, фото, звонки и карты
app/src/main/res/  иконка-автомобиль (адаптивная), темы
```
